![Portfolio Preview](https://images.unsplash.com/photo-1555066931-4365d14bab8c?w=1200)

## ✨ Features

### 🎨 Visual Excellence
- **Cinematic 3D Hero Section** - Floating geometries, particle fields, and holographic rings
- **Glassmorphism Design System** - Modern, premium UI with blur effects and gradients
- **Custom Cursor** - Magnetic interactions and smooth animations
- **Responsive Design** - Fully optimized for desktop, tablet, and mobile

### 🤖 AI Integration
- **Intelligent AI Assistant** - Context-aware responses about skills, projects, and experience
- **Natural Language Processing** - Understands and responds to user queries
- **Typing Indicators** - Real-time AI thinking animation

### 💻 Interactive Terminal
- **Linux-Style Interface** - 15+ commands with rich responses
- **Command History** - Navigate with arrow keys
- **Auto-Completion** - Tab key command completion
- **Matrix Effect** - Hidden easter egg animation

### 📊 Real-Time Analytics
- **GitHub Integration** - Live stats, contributions, and repository data
- **Interactive Charts** - Language distribution and contribution trends
- **Activity Feed** - Recent commits, PRs, and stars

### 🎯 Project Showcase
- **3D Tilt Cards** - Interactive project display with hover effects
- **AI-Generated Summaries** - Intelligent project descriptions
- **Category Filtering** - Filter by technology or project type

### 📅 Career Timeline
- **Cinematic Timeline** - Visual journey of milestones and achievements
- **Parallax Effects** - Smooth scroll-based animations
- **Statistics Dashboard** - Key metrics at a glance

## 🛠️ Tech Stack

### Frontend Core
- **React 19** - Modern UI framework
- **Vite** - Next-generation build tool
- **Tailwind CSS** - Utility-first styling

### 3D & Animations
- **Three.js** - 3D graphics library
- **React Three Fiber** - React renderer for Three.js
- **Framer Motion** - Production-ready animations
- **GSAP** - High-performance animations

### State & Data
- **Zustand** - Lightweight state management
- **TanStack Query** - Async state management
- **Axios** - HTTP client

### AI & Terminal
- **OpenAI API** - AI assistant integration
- **XTerm** - Terminal emulator

### Charts & Visualization
- **Recharts** - Composable charting library
- **Date-fns** - Date manipulation
